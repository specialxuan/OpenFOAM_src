# AGARD 445.6 机翼模态材料刚度标定说明

## 算例目的

AGARD 445.6 半展机翼，用 CalculiX 模态分析标定正交各向异性材料刚度，使前 4 阶固有频率匹配实验。

## 几何与网格

- 网格来源：由一阶 C3D4 AGARD 445.6 实体导出升级而来的二阶 C3D10；完整来源（源修订版 sha256、规范副本）与全部计数见"最新标定（二阶 C3D10 网格）"一节。
- 当前（二阶）网格：977,086 节点、532,373 个 C3D10 单元、2,930,679 个方程；NSET：`ROOT` 193、`TIP` 212、`SIDE` 510,058、`WING` 977,086。
- 坐标框架：x = 弦向 0..1.1778 m、y = 展向 0..0.762 m、z = 厚度方向。
- 半展长 0.762 m、根弦 0.558 m、后掠约 45°。
- 早期的一阶 C3D4 网格已弃用，原因见"最新标定"一节。

## 材料坐标轴（修正后的映射）

- 当前网格坐标框架：x = 弦向、y = 展向、z = 厚度（见"几何与网格"）。
- 轴1（展向/弹性轴，longitudinal）方向 = (1,1,0)/√2
- 轴2（厚度/radial）方向 = (0,0,1)
- 轴3（弦向/transversal）方向 = (1,-1,0)/√2
- 原因：机翼后掠约 45°，弹性轴为 (1,1,0)；厚度为全局 z；弦向为与轴1垂直的 (1,-1,0)。对应 CalculiX 单行 `1,1,0, 0,0,1`。

## CalculiX 卡片规则（必须遵守）

- `*ORIENTATION, NAME=WING_AXES` 后用**单行**数据 `1,1,0, 0,0,1`（RECTANGULAR：前三个数是局部 X′ 轴上的点 a，后三个数是 X′-Y′ 平面内的点 b；本行给出 轴1=(1,1,0)/√2、轴2=(0,0,1)、轴3=(1,-1,0)/√2）。
- `*ELASTIC, TYPE=ENGINEERING CONSTANTS`（**不能用 `TYPE=ORTHO`**——CalculiX 的 `ORTHO` 要的是刚度系数，用工程常数会得到错误的软材料）。
- 常数顺序：`E1,E2,E3,nu12,nu13,nu23,G12,G13` 一行，`G23,0.` 第二行。
- `*BOUNDARY` 为 `ROOT,1,3`；`*FREQUENCY` 取 4 阶（数据行 `4,0.334,1.E6`），且不使用 `STORAGE=YES`（实测对模态计算无内存收益；本流程每次只取 4 阶）。

## 最新标定（二阶 C3D10 网格）

- **网格来源**：一阶 C3D4 AGARD 445.6 实体导出的只读源（源修订版 sha256 `c663c1d2c456e7d752742c8429b609c721712a8f9772bf6ecb300e2a66185cbd`）升级为二阶四面体（`Mode/pure_wing/AGARD4456_wing_mesh_and_calibration_provenance.zip` → `upgrade_c3d10.py`，等价的 setOrder(2) 中边节点插入；原 `ModeTweak4/` 目录已于 2026-09-24 退役）；升级后的机翼网格规范副本为提交的 `case/AGARD/Mode/mesh/wing_c3d10.zip` 成员 `wing_c3d10.inp`（sha256 `071d8d0e0f4e93d8015214349e56755868e9d32fbe61168be41dd6e3b7fce5b0`），得到 977,086 节点 / 532,373 个 C3D10 / 2,930,679 个方程；NSET：`ROOT` 193 / `TIP` 212 / `SIDE` 510,058 / `WING` 977,086。
- **为什么用二阶**：早期一阶 C3D4 网格存在剪切锁定/伪刚度，标定把 E1 推到 4.24 GPa、把 E2 压到 8.9 MPa，并把软机翼的第二阶弯曲（本应高于一阶扭转）压到了一阶扭转之下，模态次序被扭曲；二阶 C3D10 消除这一伪刚度后次序恢复正常。
- **坐标轴映射**：`WING_AXES = 1,1,0, 0,0,1`，轴1 = 展向/弹性轴 → E1、轴2 = 厚度 → E2、轴3 = 弦向 → E3。
- **选型规则（硬机翼约束最小最大 / 软机翼一阶锚定）**：固定材料的模量形状后，硬机翼取**同一形状的无约束 minimax**，并把一阶误差约束在 `|e1| ≤ 0.75%` 以内；之所以不取一阶精确锚定，是因为精确锚定会把硬机翼 2~4 阶最大误差抬到 4.4363%，而允许一阶付出 0.742% 后可将最大误差降到 3.6123%（e1 = -0.7421%，仍在 0.75% 上限内），且零额外求解成本。软机翼仍取一阶精确锚定（e1 ≈ 0，2~4 阶最大误差 2.9514%）。
- **尺度的来源**：由解析恒等式 `f(s·m) = √s · f(m)`，缩放整套模量只改变频率尺度、不改变模态形状。软机翼取一阶锚定尺度 `s_a = (T1 / f1_raw)² = 0.372323058`，使 f1 精确等于 T1；硬机翼取解析的 minimax 尺度 `t = 2/(u₂+u₃) = 1.035663139`（`s = t² = 1.072598137`），是在 `hard_e1_0p5` 形状上仅作尺度缩放的闭式解。两者都是解析的、**零额外求解成本**（无需重跑）。
- **材料稳定性门**：要求 `E3/E2 < 1/nu23² = 9.4095`；硬机翼 2.382674、软机翼 4.913，均通过；刚度矩阵正定，E1 落在 [1, 20] GPa。
- **验证方法**：用精确的绝对常数做一次全新的干净目录重跑，要求退出码 0、日志出现 `Job finished` 与 SPOOLES 求解器横幅；模态次序为 `[1,2,3,4]`；与拟合频率的一致性 ≤ 1e-6 相对误差；并做模态身份检查（参与因子、面内位移守卫、特征向量场相关性、展向符号变化剖面）以排除弯曲/扭转次序互换。硬机翼满足 `|e1| ≤ 0.75%`（实测 -0.7421 %），测量与解析频率一致性 ≤ 2.7e-7 相对误差，模态次序 `[1,2,3,4]`，单次墙钟 277.92 s；软机翼 `verify_f1_resid = 1.04e-07`，频率一致性 ≤ 2.9e-7 相对误差，单次墙钟 280 s。两套门限全部通过，峰值 RSS ≈ 11.13 GB，模型 2,930,679 个方程。
- **误差与代价（诚实说明）**：硬机翼用一阶 -0.742% 的小偏差换来了更低的 2~4 阶最大误差（3.6123% vs 精确锚定的 4.4363%）；软机翼的一阶锚定则不需付这个代价（2.9514% 已优于软机翼的 minimax 3.0868%，同时保持 e1 ≈ 0）。两套都与论文材料值有偏离（硬机翼 G12 0.234 GPa vs 论文 0.623；软机翼 E3 1.31 GPa vs 论文 0.347），说明拟合吸收了网格/边界/模型误差。做频率匹配没问题，但用于应力评估或非设计工况时应注明这一点。

## 验证

- 网格转换验证（历史，原 ANSYS 导出网格）：用 ANSYS 的 Solid-1 常数（ANSYS 全局坐标系，ANSYS→CalculiX 映射 nu13=PRXZ、nu23=PRYZ、G13=GXZ、G23=GYZ），CalculiX 精确复现了 ANSYS Block-Lanczos 频率：5.6082 / 26.5306 / 63.5521 / 66.7630 / 98.9417 Hz。这验证了 C3D10 节点序、根部约束、密度与频率解析。
- 当前二阶网格 + 标定材料：按"最新标定（二阶 C3D10 网格）"一节的验证方法做全新干净重跑，两套均通过（退出码 0、`Job finished`、SPOOLES 横幅、模态次序 [1,2,3,4]、门限全过）：硬机翼满足 `|e1| ≤ 0.75%`（实测 -0.7421 %）、频率一致性 ≤ 2.7e-7、墙钟 277.92 s；软机翼频率一致性 ≤ 2.9e-7、墙钟 280 s。

## 灵敏度结论

以下中心差分数值来自上一代网格的研究，仅作参考；其定性结论与网格无关。

- 前 4 阶频率几乎只由 E1（展向模量，弯曲）与 G13（展-弦面内剪切，扭转）控制。
- 1% 中心差分灵敏度 ∂ln f/∂ln p：E1 = 0.465/0.243/0.259/0.248；G13 = 0.028/0.238/0.230/0.226；E3 = 0.007/0.017/0.008/0.022；G12 约 0.001~0.004；E2 与 G23 近似为 0。
- 因此 4 个模态只能辨识 E1 与 G13（E3 微弱），无法唯一确定 6 个模量。

## 注意事项

- **本算例网格是未削弱的实心机翼**，因此 `soft_anchored`（对应论文 Model No.3 "Weakened3"）得到的是**等效材料常数**（吸收了缺失的钻孔/几何软化），不是物理材料识别；这些常数只能配合这套二阶网格使用。
- `hard_e1_0p75`（对应论文 Model No.1 "Solid1"）同样是等效常数拟合，也只能配合这套二阶网格使用。
